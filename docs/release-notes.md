### Что нового в 1.0.1 / What's new in 1.0.1

- **Исправлено: «Модем уже в MUX».** Терминал больше ничего не отправляет от себя (ни AT+CMUX, ни SABM/MSC,
  ни CLD/DISC при ошибке и остановке) — только раскладывает кадры по вкладкам. Раньше повторный SABM мог «провалить»
  запуск, после чего терминал сам выключал MUX модема.
- **Исправлено: кадры длиннее 127 байт** (модем игнорирует N1 или MUX включён с другими параметрами) больше не теряются.
- Fixed "modem already in MUX": passive attach, nothing is sent on start/stop. Fixed dropping of frames longer than 127 bytes.

### Возможности / Features

- Мультиплексор GSM 07.10 / 3GPP TS 27.010 (Basic Option) на одном COM-порту, без драйверов; каналы — во вкладках.
- «Открыть порт» — обычный AT-терминал; «Старт MUX» / «Стоп MUX» — без закрытия порта.
- Вкладки: разделение окна, вынос в отдельные окна, раскладка запоминается.
- Подсветка по типам текста и правилам поиска, «Копилка» важных строк, быстрые команды, отправка файла.
- Надёжность: вывод модема из «зависшего» MUX, переподключение, журналы сеансов и ошибок.
- Встроенный эмулятор модема для проверки без оборудования.

Проверено автотестами (372) и в Wine; на реальном модеме и Windows 7 — пройдите чек-лист `docs/TESTING.md`.
