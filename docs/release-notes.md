### Возможности / Features

- Мультиплексор GSM 07.10 / 3GPP TS 27.010 (Basic Option) на одном COM-порту, без драйверов; каналы — во вкладках.
- «Открыть порт» — обычный AT-терминал; «Старт MUX» / «Стоп MUX» — без закрытия порта.
- Вкладки: разделение окна, вынос в отдельные окна, раскладка запоминается.
- Подсветка по типам текста и правилам поиска, «Копилка» важных строк, быстрые команды, отправка файла.
- Надёжность: вывод модема из «зависшего» MUX, переподключение, журналы сеансов и ошибок.
- Встроенный эмулятор модема для проверки без оборудования.

Проверено автотестами (361) и в Wine; на реальном модеме и Windows 7 — пройдите чек-лист `docs/TESTING.md`.
