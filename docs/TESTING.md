# Приёмка на реальном оборудовании

Автотесты и эмулятор проверяют протокол, но не конкретный модем, драйвер USB и Windows 7 клиента.
Перед передачей клиенту пройдите этот список на его машине (или на такой же Windows 7 SP1 с тем же модемом).
Если пункт не проходит — пришлите `%AppData%\MuxTerminal\logs\session-….log` (журнал сеанса)
и, если есть, `crash.log` (меню «Файл»), а также сведения из «Справка → О программе → Копировать сведения».

## 1. Установка

- [ ] На Windows 7 SP1 установлен .NET Framework 4.8 (`ndp48-x86-x64-allos-enu.exe`); «О программе» показывает «.NET Framework 4.8».
- [ ] `MuxTerminal.exe` запускается из любой папки без других файлов; антивирус/SmartScreen не блокирует
      (если блокирует — подписать exe, см. README).
- [ ] Иконка видна в Проводнике и на панели задач; «Свойства → Подробно» показывают версию и copyright.

## 2. Подключение

- [ ] Список портов содержит COM-порт модема (кнопка «Обновить» после подключения USB).
- [ ] «Старт MUX» с `AT+CMUX=0` → открываются DLC1..3, в строке состояния «MUX работает», ошибок FCS 0.
- [ ] Если модему нужны параметры (`AT+CMUX=0,0,5,127,10,3,30,10,2` и т.п.) — работает с ними; N1 в строке состояния совпадает.
- [ ] С включённым RTS/CTS (если модем подключён по UART с управлением потоком).
- [ ] Скорость порта: если в команде указан port_speed, отличный от выбранной скорости, программа предлагает
      переключиться — после «Да» связь сохраняется.
- [ ] «Стоп MUX» → модем отвечает на `AT` в обычном терминале (вернулся в AT-режим).
- [ ] Закрыть программу во время работы MUX (крестик) → модем в AT-режиме.
- [ ] «Зависший» MUX: запустить MUX, завершить программу через Диспетчер задач, запустить снова и «Старт MUX» →
      в логе «Модем вернулся в AT-режим», MUX запускается.

## 3. Каналы

- [ ] DLC1: `ATI`, `AT+CSQ`, `AT+CREG?` — ответы только в своей вкладке.
- [ ] DLC2: отправка SMS (`AT+CMGF=1`, `AT+CMGS="номер"`, текст, Ctrl+Z) — SMS доходит.
- [ ] Входящая SMS/звонок: `+CMTI`/`RING` подсвечиваются и попадают в «Копилку».
- [ ] GPS/NMEA (если модем умеет, например `AT+QGPS=1` / `AT+CGPS=1`) идёт в свою вкладку, остальные каналы не тормозят.
- [ ] Одновременная работа: быстрые команды в DLC1 и DLC2 во время потока NMEA — без ошибок FCS.
- [ ] Закрыть и снова открыть канал кнопками «Закрыть»/«Открыть»; открыть DLC4 кнопкой «+ Открыть канал».
- [ ] HEX-режим и HEX-ввод; двоичные данные с байтом 0xF9 отображаются без потерь.

## 4. Сбои связи

- [ ] Выдернуть USB-модем во время работы → «Соединение потеряно», программа не падает.
- [ ] С включённым «Переподключаться»: вернуть модем (или `AT+CFUN=1,1`) → через несколько секунд «Связь восстановлена».
- [ ] «Стоп MUX» во время попыток переподключения прекращает их.

## 5. Окна и настройки

- [ ] Вынести вкладку в отдельное окно, вернуть, разделить справа/снизу; перетаскивание мышью.
- [ ] Закрыть и открыть программу — раскладка, размер и положение окна восстановились.
- [ ] Переименовать вкладку (F2), имя сохраняется.
- [ ] Профиль подключения: сохранить, переключиться на другой, удалить.
- [ ] Настройки отображения: шрифт, фон, темы, скрытие времени/системных сообщений, правила подсветки — применяются сразу.
- [ ] Быстрые команды: последовательность выполняется с ожиданием OK; повторное нажатие останавливает.
- [ ] Отправка файла (построчно и двоично), вставка нескольких строк.
- [ ] Журнал сеанса появился в папке журналов и содержит обмен по каналам.

## 6. Длительная работа

- [ ] 8+ часов с потоком NMEA: память процесса не растёт неограниченно (Диспетчер задач), интерфейс отзывчив.
