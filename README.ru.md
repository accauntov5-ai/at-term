# GSM 07.10 MUX Terminal

[English](README.md) | **Русский**

Терминал для сотовых модемов под Windows: сам реализует **мультиплексор GSM 07.10 / 3GPP TS 27.010**
(Basic Option) — без драйверов — и показывает каждый логический канал (DLC) в своей вкладке через один COM-порт.

![иконка](src/MuxTerminal.App/Assets/app.png)

## Скачать

**[Последний релиз → MuxTerminal.exe](https://github.com/accauntov5-ai/at-term/releases/latest)** — один файл, установка не нужна.

Нужны **Windows 7 SP1 или новее** и **.NET Framework 4.8**
(в Windows 10 1903+ и 11 уже есть; для Windows 7/8.1 — установщик `ndp48-x86-x64-allos-enu.exe` с сайта Microsoft).

## Как начать

1. Выберите COM-порт модема и скорость (или **Эмулятор модема** — проверить без оборудования).
2. **Открыть порт** — обычный AT-терминал на вкладке «COM-порт» (проверить модем: `AT`, `ATI`, `AT+CPIN?`).
3. **Старт MUX** — модем переходит в `AT+CMUX`, каналы DLC 1–3 открываются в своих вкладках.
4. **Стоп MUX** — обратно в обычный AT-терминал; **Закрыть порт** — готово.

## Возможности

- Мультиплексор: разбор кадров с FCS и ресинхронизацией, flow control, MSC, нарезка по N1, корректное закрытие
  (DISC + CLD), вывод модема из «зависшего» MUX, автоматическое переподключение.
- Окна: вкладку можно перетащить — разделить окно или вынести в отдельное окно; раскладка запоминается.
- Терминал: текст/HEX, время, история команд, кнопки быстрых команд и последовательности, отправка файла.
- Подсветка: цвета и моноширинные шрифты по типам текста; правила поиска подсвечивают совпадения и собирают
  важные строки (ошибки, звонки, новые SMS) во вкладку **«Копилка»**.
- Журналы сеансов и журнал ошибок в `%AppData%\MuxTerminal`.
- Встроенный эмулятор модема (AT-команды, SMS, поток NMEA, двоичные данные, перезагрузка).
